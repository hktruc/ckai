## Entry contract

When Product Owner and ChatGPT deliberately select a reference, add one entry with:

- stable reference ID;
- category;
- source/title and real URL or local reference artifact;
- selection authority and date;
- what CKAI should learn;
- what must not be copied;
- rights/usage boundary (`REFERENCE_ONLY` unless separately approved);
- representative timestamp/frame when relevant;
- relationship to `CKAI_MARKET_TASTE_STANDARD_V1` dimensions.

Reference selection supplies taste calibration, not evidence authority, Content Approval, Release Approval, or permission to copy protected work. Production asset use remains governed by [`../README.md`](../README.md).
