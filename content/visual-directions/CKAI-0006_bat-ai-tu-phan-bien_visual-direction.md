# CKAI-0006 — Visual Direction V1

## Direction

`PRACTICAL AI WORKSPACE / SELF-CRITIQUE LOOP`: a clean, useful working surface that makes the workflow understandable even without narration.

## Visual system

- Warm cream workspace, navy ink, teal success, coral critique and restrained amber scan highlight.
- Large mobile-readable typography in a stable upper-left region.
- Code-native answer cards, step controls, status chips and before/after panels; no abstract nodes, decorative HUD or CKAI-0005 material metaphor.
- Two semantic hero motions: critique scan/issues surfacing and V1 → V2 rewrite transformation.

## Generalization boundary

The workflow-state clarity, stable reading region and meaning-changing hero motion are transfer candidates. The palette, UI card anatomy and exact critique/rewrite choreography remain CKAI-0006-specific until reviewed across later content.

## V1.1 candidate practical visual rules

1. Practical CKAI content should use editorial/broadcast moving-image language rather than presentation-deck grammar.
2. UI should function as an object or depth layer inside a scene, not the entire scene.
3. Practical workflow videos benefit from real shot grammar: wide, medium, close, insert and hero.
4. Camera movement should carry semantic purpose.
5. Before/after improvement should preferably be shown as transformation, not card replacement.
6. If representative frames resemble slides, landing pages, dashboards or report cards, visual repair is required.

These remain candidates from the first major test and are not promoted to universal baseline.

## V1.2 candidate refinement

- Broadcast/editorial moving-image language is the preferred candidate direction for Practical CKAI.
- Workflow is the narrative content; UI is one actor inside a larger scene.
- Practical visual relevance should be direct: narration beat → visual evidence/action.
- Shot variety matters independently from aesthetic quality.
- Perspective UI alone does not automatically remove presentation grammar.
- Freeze-frame QA must ask whether a frame looks like a media shot, not merely whether it looks polished.
- Animation is one tool inside moving-image communication, not the defining visual philosophy.

V1.2 supplies stronger evidence but does not promote these rules to universal baseline before human review and another content-ID test.
