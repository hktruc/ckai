# content/ideas/

Output của `/ck-idea`, `/ck-expand`, hoặc teaching brief `AITIP-*` đã được Product Owner approve và handoff được lưu ở đây, mỗi file 1 Content ID.

- Tên file: `CKAI-000N_slug.md`
- Chứa: metadata YAML + `content_stream` + Big Idea + angle(s) + hook gợi ý — **chưa** có full script.
- Khi một idea được chọn, giữ file này (đổi `status` sang `scripting`) và tạo script cùng Content ID theo [`../../engine/script-engine.md`](../../engine/script-engine.md).
- Với `tuyet-chieu-ai`, file phải ghi `source_candidate: AITIP-000N`; candidate nguồn phải còn `decision: recommend`, `human_decision: approved` và `content_id` khớp. `/ck-script` không được đọc trực tiếp candidate pending.
- Không copy toàn bộ evidence/test logs; script tham chiếu claim/evidence cần dùng và giữ caveat decision-critical.
- `chanh-kien` không cần `source_candidate` và không đi qua AI Tips Intelligence.
