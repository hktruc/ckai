# content/ideas/

Output của `/ck-idea` và `/ck-expand` được lưu ở đây, mỗi file 1 Content ID.

- Tên file: `CKAI-000N_slug.md`
- Chứa: metadata YAML + Big Idea + angle(s) + hook gợi ý — **chưa** có full script.
- Khi 1 idea được chọn để viết script, giữ nguyên file này (đổi `status` sang `scripting`), tạo file mới trong `../scripts/` cùng Content ID.
