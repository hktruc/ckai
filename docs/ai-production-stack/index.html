§8 — Key Findings
8 Audit Conclusions
Finding 01
Vbee is the correct primary TTS provider
Native Vietnamese quality, production-approved, with proper per-job authorization controls. Piper is proof-only and not suitable for production. FPT AI TTS is the only viable secondary if Vbee becomes unavailable.
Finding 02
OpenAI image generation is opt-in and bounded
Maximum 9 API calls and optional USD cap prevent runaway costs. This is the right governance model. gpt-image-2 is the correct default; DALL-E 3 is the simplest fallback.
Finding 03
No auto-purchase anywhere in the stack
Vbee credits and OpenAI usage require explicit per-job authorization. The allowVbeeQuota contract field and disabled auto_purchase_credits flag are the strongest cost control mechanisms in place.
Finding 04 ⚠
gpt-5.6-terra model ID needs verification
This is the only unconfirmed model designation in the production stack. Standard OpenAI model naming does not include a "terra" suffix as of May 2026. Verify via the OpenAI platform dashboard or API /models endpoint before relying on it.
Finding 05
Local infrastructure dominates the stack
Remotion (local), FFmpeg (local), and music library (local files) mean AI cloud cost is only Vbee + optional OpenAI. This is a genuinely low-cost production model. Annual cloud ceiling likely under $500 at 1–3 videos/week.
Finding 06
Zero vendor lock-in on rendering
FFmpeg and Remotion are open/local standards. The only real dependencies are Vbee for voice and OpenAI for visual intelligence. Both have parameterized env-var overrides for model selection.
Finding 07
Quality governance is well-structured
Viewer Reality Gates with explicit failure modes (PRODUCT_REJECT, NOT_MARKET_READY, NO_COMMERCIAL_VALUE), Quality League with 8 progression levels, and SHA-256 source chain integrity are all production-grade mechanisms.
Finding 08 ⚠
Cost logging is the main operational gap
No per-video cost records exist in runtime/learning/. Adding automatic cost logging to the production bridge would complete the governance loop and enable volume economics analysis.
